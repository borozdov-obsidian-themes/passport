# Borozdov Passport

A theme from the Borozdov collection. Two faces — light **Boarding**, a playful passport on
a pale sky, and dark **Nightflight**, the same passport on a red-eye over the ocean.
Friendly bold headlines, a spring-mint pill for what you act on, a gradient sky card and
round everything.

![Borozdov Passport in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/passport/main/screenshots/light.png)

![Borozdov Passport in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/passport/main/screenshots/dark.png)

## Principles

- **A sky card.** The plain note is a card of indigo-to-blue sky with white text and a mint
  title, on both faces.
- **Mint is rare.** Spring mint fills only the main button; signal blue carries links, a
  checked task, the toggle, tags and outlined buttons; a mint wash is the highlighter.
- **Round everything.** Round checkboxes, pill buttons and tags, callout icons in round
  badges tinted by type, 16px on cards.
- **A friendly voice.** Passport Sans, from Andika, a typeface drawn for new readers, sets
  the title and the two largest headings.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- The plain note as a gradient sky card
- Callouts as white cards with the icon in a round badge
- Round checkboxes and outlined pill buttons in signal blue
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory, as a variant:** this theme ships inside **Borozdov
Palette**. Install Borozdov Palette under Settings → Appearance → Themes → Manage, then
the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin, and
choose **Passport** under Style Settings → Borozdov Palette → Variant. The variant brings
this theme's palette, type and corners; its own layout, and its embedded font if it has
one, come with the full theme below.

**The full theme, by hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/passport/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Passport/`, then choose Borozdov Passport under Settings
→ Appearance → Themes.

## Font

Passport Sans is embedded in `theme.css` as base64 WOFF2 under the SIL Open Font License 1.1
— see [`fonts/OFL.txt`](fonts/OFL.txt). It is a Latin and Cyrillic subset of Andika Bold (©
2004–2022 SIL International), renamed because a modified copy may not use the original's
Reserved Font Name. One weight, for the title and the two largest headings only.
